--CONTEXTO INICIAL--

Idea inicial. Crear un CRM enfocado a la administración de APIs, clientes y potenciales clientes para una empresa de servicios de automatización para pequeñas y medianas empresas. El objetivo es organizar lo mejor posible desde un inicio todos los datos y poder gestionar de forma organizada todos los proyectos con una organizacion muy estructurada.

El CRM deberá permitir gestionar:
- Clientes
- Posibles clientes
- APIs específicas
- APIs plantilla
- Contratos
- Facturas
- Sistema de etiquetas (tags)
- Búsquedas globales
- Relaciones entre entidades

Además, el sistema deberá ser modular y fácilmente ampliable.


--TECNOLOGIAS--

Backend:
RUST.

Frontend:
El frontend funcionará mediante llamadas HTTPS a la API de nuestro dominio (todavía no definido, por lo que inicialmente funcionará en local). La interfaz estará desarrollada con TailwindCSS.

Base de datos:
PostgreSQL.

SISTEMA DE TAGS
---------------------------------------------------

El CRM tendrá un sistema de etiquetas global reutilizable para permitir:
- búsquedas avanzadas
- filtros
- clasificación
- autocompletado
- categorización de registros

Las etiquetas podrán aplicarse a:
- clientes
- posibles clientes
- APIs específicas
- APIs plantilla

Ejemplos de etiquetas:
#Spring_boot
#Docker
#Webhook
#IA
#Automatizacion
#Urgente

SISTEMA DE BUSQUEDA GLOBAL
---------------------------------------------------

Todos los módulos tendrán una barra de búsqueda global.

La búsqueda podrá realizarse mediante:
- nombre
- CIF
- id
- etiquetas

Las etiquetas se identificarán mediante el prefijo "#".

Ejemplo:

#Spring_boot

La búsqueda deberá devolver todos los registros que tengan asociada dicha etiqueta.

El sistema deberá permitir:
- búsqueda parcial
- autocompletado
- múltiples tags
- filtros dinámicos

Ejemplo:

#Spring_boot #Docker
