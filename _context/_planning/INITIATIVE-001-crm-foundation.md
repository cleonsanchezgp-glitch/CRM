## 1. Overview

This initiative establishes the CRM foundation for managing Aelium customers, prospects, commercial documents, incidents, tags, search, local operation, production identity readiness, and business-specific service modules such as API assets. Planning authority is Markdown in this repository for now. No separate test-infrastructure initiative is included in this version because no dedicated test-infrastructure stream has been identified yet.
