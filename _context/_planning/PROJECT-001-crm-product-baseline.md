This project organizes the first delivery baseline for the CRM: core modules, search/tags, local platform operation, and Keycloak-based production identity readiness.

## 4. Scope

### In Scope

- Core CRM module completion and relationship visibility.
- Search and tag consistency.
- Local platform and API reliability.
- Keycloak architecture and integration plan for production user management.
- Explicit backlog visibility for production authentication, secure attachments, CRUD gaps, and AI chatbot provider integration.

### Out of Scope

- Final production hosting implementation.
- Full AI chatbot implementation.
- Secure attachment storage implementation unless separately planned.
- Dedicated test-infrastructure initiative.
